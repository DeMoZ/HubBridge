# Tasks

Spec: `specs/host-session/spec.md`. How: `design.md` (decision numbers below refer to it).
Rules from CLAUDE.md apply: the protocol does not change (no `PROTO_VERSION` bump, no new
`Message` variants, `docs/PROTOCOL.md` untouched); never print key files; any manual
simulator run uses `HUBBRIDGE_HOME=<scratch>` and `--state-dir <scratch>` and a free
`--listen 127.0.0.1:<port>`. Tests must not depend on wall-clock luck: use generous outer
timeouts (≥ 5 s) around the assertions and short inner ones only to force a cancellation.
