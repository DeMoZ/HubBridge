## What's new

First release of HubBridge: use the USB devices on your Android phone's hub from your computer.

- **Wi-Fi/LAN and ADB bridge.** The phone runs HubBridge as a foreground service; the computer finds it on the local
  network or reaches it through `adb forward`. Sessions are encrypted.
- **PIN pairing.** Pair once with the 6-digit PIN the phone shows; later connections need no PIN.
- **Desktop window** for macOS: phones on the network and over adb, connect and auto-reconnect, live round-trip time,
  "Install app" for the phone, ADB over Wi-Fi and wireless-debugging pairing.
- **USB device list** with configurations, interfaces and endpoints, hot-plug events and a button that asks the phone
  for USB permission.
- **Serial bridge** for CDC-ACM, CP210x, FTDI and CH34x adapters: a PTY, raw TCP or RFC 2217. It is tested with
  simulated devices only, not yet with real adapters.
- **In-app updates.** The window checks GitHub releases once a day and can download, verify and install a new version.
- **Support button** with ways to support the development.

The macOS app is for Apple Silicon. It is signed ad hoc and not notarized by Apple. There is no Windows download yet.

## Что нового

Первый выпуск HubBridge: пользуйтесь USB-устройствами из хаба Android-телефона на компьютере.

- **Мост по Wi-Fi/LAN и ADB.** HubBridge работает на телефоне как служба переднего плана; компьютер находит его в
  локальной сети или подключается через `adb forward`. Сессии зашифрованы.
- **Сопряжение по PIN.** Один раз введите 6-значный PIN, который показывает телефон; дальше PIN не нужен.
- **Окно для macOS:** телефоны в сети и по adb, подключение с автопереподключением, задержка в реальном времени,
  кнопка «Установить приложение» для телефона, ADB по Wi-Fi и сопряжение беспроводной отладки.
- **Список USB-устройств** с конфигурациями, интерфейсами и конечными точками, события подключения и отключения и
  кнопка, которая просит телефон выдать разрешение на USB.
- **Мост последовательных портов** для адаптеров CDC-ACM, CP210x, FTDI и CH34x: PTY, обычный TCP или RFC 2217.
  Пока проверен только на имитаторах устройств, на настоящих адаптерах ещё нет.
- **Обновления из приложения.** Окно раз в день проверяет релизы на GitHub и может скачать, проверить и установить
  новую версию.
- **Кнопка «Поддержать»** со способами поддержать разработку.

Приложение для macOS собрано для Apple Silicon. Оно подписано локальной (ad-hoc) подписью и не нотаризовано Apple.
Версии для скачивания под Windows пока нет.

## Install

**macOS (Apple Silicon, macOS 11 or newer)**

1. Download `HubBridge-macOS-v0.1.0.dmg`, open it and drag HubBridge to Applications.
2. On the first start macOS says that the app was **Not Opened** because Apple could not verify that it is free of
   malware. Press **Done** (not "Move to Trash"), open **System Settings → Privacy & Security**, and press
   **Open Anyway** next to HubBridge. Or remove the download flag in Terminal:
   `xattr -dr com.apple.quarantine /Applications/HubBridge.app`
3. When macOS asks whether HubBridge may find devices on local networks, press **Allow**.

**Android (8.0 or newer, USB host support)**

- Turn on USB debugging, plug the phone in and press **Install app** in the HubBridge window; or install the APK
  yourself: `adb install HubBridge-0.1.0.apk`.
- If the phone has a development build of HubBridge (signed with another key), uninstall it first. This makes the phone
  forget its paired computers.

**Command line:** `hubbridge-0.1.0-macos-arm64.tar.gz` holds the `hubbridge` tool and the phone app next to it. If macOS
refuses to run it, use `xattr -d com.apple.quarantine hubbridge`.

## Установка

**macOS (Apple Silicon, macOS 11 или новее)**

1. Скачайте `HubBridge-macOS-v0.1.0.dmg`, откройте его и перетащите HubBridge в «Программы».
2. При первом запуске macOS сообщит, что приложение не открыто, потому что Apple не может проверить, что в нём нет
   вредоносного ПО. Нажмите «Готово» (не «Переместить в Корзину»), откройте **Системные настройки →
   Конфиденциальность и безопасность** и нажмите **«Всё равно открыть»** рядом с HubBridge. Или снимите отметку о
   загрузке в Терминале: `xattr -dr com.apple.quarantine /Applications/HubBridge.app`
3. Когда macOS спросит, можно ли HubBridge искать устройства в локальных сетях, нажмите **«Разрешить»**.

**Android (8.0 или новее, с поддержкой USB-хоста)**

- Включите отладку по USB, подключите телефон и нажмите в окне HubBridge **«Установить приложение»** (в английском интерфейсе — Install app);
  или установите APK сами: `adb install HubBridge-0.1.0.apk`.
- Если на телефоне стоит сборка HubBridge для разработки (подписанная другим ключом), сначала удалите её. Телефон при
  этом забудет сопряжённые компьютеры.

**Командная строка:** в архиве `hubbridge-0.1.0-macos-arm64.tar.gz` лежат утилита `hubbridge` и рядом приложение для
телефона. Если macOS не даёт её запустить, выполните `xattr -d com.apple.quarantine hubbridge`.
